# Preran Kumar K R — Portfolio

A responsive, cinematic portfolio for AI/ML, UI/UX and creative technology.

## Run locally

No build tools are required. Open `index.html` in a browser, or run a simple local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **GitHub Actions**.
3. The included workflow deploys the static site from the `main` branch.
4. Once the workflow succeeds, open the Pages URL shown in repository settings.
